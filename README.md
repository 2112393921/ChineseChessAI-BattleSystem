# 中国象棋AI对战系统

基于 C++ + EasyX 图形库 + 皮卡鱼引擎的中国象棋人机对战系统。

## 功能特点
- 鼠标点击走棋，图形化棋盘
- 支持皮卡鱼引擎（UCI协议）和内置Alpha-Beta搜索
- 棋盘视觉翻转（红方在下，黑方在上）
- 悔棋功能（按 R 键）
- 双方走棋计时统计

## 编译运行
1. 安装 [EasyX](https://easyx.cn/)
2. 下载 [皮卡鱼引擎](https://github.com/official-pikafish/Pikafish) 放到项目目录
3. 用 Visual Studio 打开 `象棋ai.cpp`，编译运行
